# mooliife
A bilingual interactive educational simulation exploring a day in the life of a dairy cow. Built with AI-assisted coding (Vibe Coding).
## Ein Tag als Milchkuh / A Day as a Dairy Cow

**Educational Simulation · Beta Version
Basis / Base version:** v5.2

### Deutsch

**Über das Spiel**
MooLife! ist eine zweisprachige, browserbasierte Lernsimulation, in der Besucherinnen und Besucher einen Tag aus der Perspektive einer Milchkuh erleben. Das Spiel veranschaulicht unter anderem Fressen, Trinken, Wiederkäuen, Ruhen und die Bewegung innerhalb der Herde.

**Start**

1. `moolife.html` in einem aktuellen Browser öffnen.
2. Deutsch oder Englisch auswählen und der eigenen Kuh einen Namen geben.
3. Den Hinweisen im Spiel folgen. Die Steuerung erfolgt über Tastatur bzw. die eingeblendeten Bedienelemente auf Mobilgeräten.

**Technik**

* HTML, CSS und JavaScript; keine Installation oder Datenbank erforderlich.
* Die bereitgestellte Fassung ist als eigenständige HTML-Datei ausgelegt.

**Wissenschaftlicher Hinweis**
Das Spiel dient der Wissenschaftskommunikation. Tierverhalten, Tagesabläufe und physiologische Parameter sind für die Spielmechanik vereinfacht. Angezeigte Richtwerte sind keine verbindlichen Anforderungen für einzelne Tiere und ersetzen keine fachliche Tierbeurteilung.

### English

**About**
MooLife! is a bilingual browser-based educational simulation that lets visitors experience a day from a dairy cow's perspective. It illustrates feeding, drinking, rumination, resting and herd movement.

**Getting started**

1. Open `moolife.html` in a current web browser.
2. Select German or English and name your cow.
3. Follow the on-screen instructions. Use the keyboard or the on-screen mobile controls.

**Technical notes**

* HTML, CSS and JavaScript; no installation or database required.
* This release is designed as a standalone HTML file.
* University hosting is subject to approval and requirements set by the responsible web administrators.

**Scientific disclaimer**
This game is intended for science communication. Animal behaviour, daily routines and physiological parameters are simplified for gameplay. Displayed reference values are not universal requirements for individual animals and do not replace professional animal assessment.

**Release status**
Beta version: intended for testing and feedback. The label does not imply that comprehensive technical, security or accessibility audits have been completed.
