# MooLife! 🐄

**A Day as a Dairy Cow | Ein Tag als Milchkuh**

A bilingual interactive educational simulation exploring a day in the life of a dairy cow. Created as a personal science communication project using AI-assisted coding ("vibe coding").

**Educational Simulation · Beta Version · v5.2**

🎮 **Play online / Jetzt spielen:**

https://miaorwang.github.io/moolife/

Available in German and English. Free to play directly in your browser.

---

## 🇩🇪 Deutsch

### Über das Spiel

**MooLife!** ist eine zweisprachige, browserbasierte Lernsimulation, in der Besucherinnen und Besucher einen Tag aus der Perspektive einer Milchkuh erleben.

Das Spiel veranschaulicht verschiedene Aspekte des täglichen Lebens einer Milchkuh, darunter:

- Fressen und Trinken
- Wiederkäuen und Ruhen
- Bewegung innerhalb der Herde
- Melken und alltägliche Aktivitäten

Ziel ist es, Themen rund um die Milchviehhaltung und das Tierwohl auf spielerische und interaktive Weise zugänglich zu machen.

### Spiel starten

**Online:**

Das Spiel kann direkt über GitHub Pages geöffnet werden:

https://miaorwang.github.io/moolife/

**Lokal:**

1. Die HTML-Datei `index.html` in einem aktuellen Webbrowser öffnen.
2. Deutsch oder Englisch auswählen und der eigenen Kuh einen Namen geben.
3. Den Hinweisen im Spiel folgen. Die Steuerung erfolgt über die Tastatur bzw. die eingeblendeten Bedienelemente auf Mobilgeräten.

### Technische Informationen

- Entwickelt mit HTML, CSS und JavaScript.
- Keine Installation oder Datenbank erforderlich.
- Als eigenständige HTML-Datei konzipiert.
- Für Desktop- und mobile Browser ausgelegt.
- Mit KI-gestützter Programmierung („Vibe Coding“) und iterativer Überarbeitung entwickelt.

### Wissenschaftlicher Hinweis

MooLife! dient ausschließlich der Bildung und Wissenschaftskommunikation.

Tierverhalten, Tagesabläufe und physiologische Parameter sind für die Spielmechanik vereinfacht und teilweise illustrativ dargestellt.

Angezeigte Richtwerte sind keine allgemeingültigen Anforderungen für einzelne Tiere. Die Simulation ist kein wissenschaftlich validiertes Instrument zur Tierwohlbewertung und ersetzt keine fachliche oder tiermedizinische Beurteilung.

### Entwicklungsstand

**Beta-Version v5.2**

Die Simulation befindet sich in der Erprobungsphase. Rückmeldungen und Verbesserungsvorschläge sind willkommen.

Eine vollständige technische, sicherheitsbezogene oder barrierefreiheitsbezogene Prüfung ist mit dieser Versionskennzeichnung nicht zugesichert.

## 🇬🇧 English

### About the Game

**MooLife!** is a bilingual, browser-based educational simulation that allows visitors to experience a day from the perspective of a dairy cow.

The game illustrates several aspects of daily life, including:

- Feeding and drinking
- Rumination and resting
- Movement within the herd
- Milking and daily activities

The aim is to explore how interactive learning and playful approaches can make dairy farming and animal welfare topics more accessible and engaging.

### Getting Started

**Play online:**

Open the game directly through GitHub Pages:

https://miaorwang.github.io/moolife/

**Run locally:**

1. Open `index.html` in a modern web browser.
2. Select German or English and give your cow a name.
3. Follow the on-screen instructions. Use the keyboard or the on-screen controls on mobile devices.

### Technical Information

- Built with HTML, CSS and JavaScript.
- No installation or database required.
- Designed as a standalone HTML file.
- Intended for desktop and mobile browsers.
- Developed using AI-assisted coding ("vibe coding") and iterative refinement.

### Scientific Disclaimer

MooLife! is intended exclusively for education and science communication.

Animal behaviour, daily routines and physiological parameters are simplified and partly illustrative for gameplay purposes.

Displayed reference values are not universal requirements for individual animals. The simulation is not a scientifically validated animal welfare assessment tool and does not replace professional or veterinary assessment.

### Release Status

**Beta Version v5.2**

The simulation is currently intended for testing, exploration and feedback.

This designation does not imply that comprehensive technical, security or accessibility audits have been completed.
